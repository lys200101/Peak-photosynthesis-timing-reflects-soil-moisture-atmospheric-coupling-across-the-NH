# Peak-photosynthesis-timing-reflects-soil-moisture-atmospheric-coupling-across-the-NH

The original hydro-meteorological and vegetation datasets can be downloaded from the public links provided in the manuscript. The code used to preprocess the original datasets in Google Earth Engine (GEE), as well as to download and further process them in Python, is also provided. To facilitate the visualization and reproduction of Figs. 1–6, the processed vegetation and climate datasets used in these figures will be available on Figshare.
